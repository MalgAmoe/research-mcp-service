# Source provenance

This independent project starts from selected MIT-licensed source in:

- Repository: https://github.com/MalgAmoe/local-research-kit
- Revision: `097b0b6dd05b6ee3994a9e3294ea89c001efce0f`

Copied as ordinary files: `src/research_gateway/`, the interactive browser controller, research-engine/retention tests, dependency declarations/lockfile, Docker build recipe, SearXNG configuration, ignore rules and MIT license.

Not copied: Git history, secrets or `.env`, databases, fetched data, backups, browser profiles, installed dependencies, Pi/Hermes adapters, personal-agent installers or host operations scripts.

The package name, internal service defaults, deployment skeleton and documentation are maintained independently here. Future fixes must be reviewed and copied explicitly; there is no submodule, editable dependency, symlink, host mount or runtime link to the source repository. This URL and revision are provenance only, not build inputs.

The original MIT copyright and permission notice are retained in `LICENSE`.
